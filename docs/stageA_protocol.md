# 阶段 A 协议:候选条件化的视觉读出(2026-10-23 预注册;在任何阶段 A 结果出现之前固定)

## 问题

策略自己的冻结视觉表征,能否在**候选主动查询**的读出方式下,帮助区分同一场景里哪条候选更好?只回答这一个问题。**不更新策略,不启动阶段 B,不增加网络规模。**
阴性结论的措辞(预先写定):在当前数据量、冻结表征和读出结构下,候选条件化读取没有显示稳定增量;这不证明视觉表征缺少信息。

## 数据与划分(不得在 navtest 上选方案)

- 训练:日志隔离清单 `manifest_v2.json` 的 3481 个训练场景(每场景 64 个带仿真标签的候选)。
- 开发池:同清单的 3690 个留出池场景(341 个日志)。**按日志**用固定种子划成两块:`tune`(约 70% 日志,用于调超参、选 epoch 数)和 `decision`(约 30% 日志,**只用于最后一次继续/停止判断**,此前不得查看其评价结果)。
- navtest(12146 场景):称为"本阶段锁定方案后的评测",**不是确认性检验**(项目此前已反复查看过它);只在方案锁定后评一次。
- 仿真标签只用于训练与最终评价,不参与测试时选择。

## 输入(冒烟确认布局之后才定稿)

- 视觉:策略 VLM 流在所有共享层之后、视觉 token 位置的隐藏状态,用固定随机投影(种子 0)降到 128 维,半精度缓存。
- **冒烟结果(2026-10-23,作业 64668120,20 个池场景)**:每个场景 1152 个视觉 token = **2 帧 × 576**,每帧是**一整段连续的 token**(视频 prompt 里没有按行的 eol 分隔),无非视觉 token 混入;序列长度约 1200,隐藏维度 4096。每帧是 `[18, 32]` 的行优先展平(数据集代码 `frame.flatten()`),所以帧内第 k 个 token 对应行 `k // 32`、列 `k % 32`。帧按时间顺序取(索引步长 2、即约 1 秒间隔,最后一帧是当前帧;这条来自读代码,评价器给两帧各一个可学习的帧嵌入,**不依赖这个顺序**)。
- **成本(冒烟测得,外推)**:每场景 0.10 秒、294,912 字节(1152×128 半精度);池 + navtest 共 19317 个场景外推约 0.6 GPU 小时(不含约 15 分钟的模型加载)、5.7 GB。
- 生产提取脚本强制检查该布局(`--expect-frames 2 --frame-grid 18x32`),任何场景的布局不同即中止。
- 候选:相对自车坐标系下 8 个路点 (x, y, yaw) 及其相对参考输出的偏差。

## 变体(尽量匹配容量与训练预算;不要求结构完全相同)

共享:轨迹编码器、输出头、损失、优化器、训练步数预算、3 个训练种子(0,1,2)。

| 变体 | 视觉读出 | 角色 |
|---|---|---|
| a | 无 | 辅助下限 |
| b | 池化视觉向量作为**单个**上下文 token | 对照(**不使用**旧 HGB 的 +0.53 作为 b) |
| **c** | 候选查询全部视觉 token(交叉注意力,带 2D 位置编码) | **唯一主改动** |
| d | 与 c 完全相同,但视觉 token 取自**另一个场景** | 对应关系对照 |
| e | 真实地图几何特征(15 维)作为输入 | 特权参照,**不是理论上限** |

- 参数量:报告每个变体的可训练参数量;b 与 c 的差距应尽量小(通过隐层宽度匹配),差距写入结果。
- d 的打乱:在**各自数据划分内部、跨日志**打乱,固定种子,保证不匹配回原场景,不跨划分交换表示。
- 附加检查(不增加训练):对训练好的 c,在开发集**推理时**打乱视觉 token,观察选中候选的 PDMS 是否下降(检查 c 是否依赖正确的场景信息;与独立训练的 d 回答不同问题)。

## 损失与选择规则(所有变体相同,先固定)

- 主任务:场景内 PDMS 排序——对场景内中心化的 PDMS 做回归(均方误差)。
- 辅助监督:DAC、NC、TTC 的通过(二元交叉熵)、连续几何量(越界比例、最小净距等,标准化后均方误差);辅助项权重固定为主任务的 0.5,不调。
- 推理:对每个场景的候选,按**同一个**预测的 PDMS 分数取最大者。不同时更换输入、奖励定义和选择规则。

## 调参

- 小网格,所有变体(b、c、d)使用**相同的网格**:学习率 {3e-4, 1e-3} × dropout {0, 0.1},固定训练步数。
- 在 `tune` 上按选中候选的平均 PDMS 选一个配置,冻结后在 `decision` 上评一次。

## 主比较与继续/停止规则(在 `decision` 子集上,3 个种子的场景级平均)

主比较(选中轨迹 PDMS 的配对差,整日志自助法):
1. c − b
2. c − d

**多重比较**:两个主比较各用 97.5% 整日志区间(Bonferroni,总体 α=0.05)。

**继续阶段 B 的条件需同时满足:**
1. 两个主比较的 97.5% 区间下限都 > 0。
2. 安全分项(**NC、DAC、TTC 分别报告**,不合计):以同场景的**参考探针**为参照,c 选中的轨迹在每一项上的"修复数 − 新增失败数"相对 b 不得显著更差(该项配对差的 95% 整日志区间不得整体落在 0 以下);三项净值之和也不得低于 b。
3. 3 个种子中至少 2 个种子单独的 c − b 与 c − d 均为正。

**否则停止这条分支**:不加大网络、不加长训练、不换成新的 RL 链条。
